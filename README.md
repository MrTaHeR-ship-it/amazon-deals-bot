# بوت عروض أمازون مصر على تليجرام

البوت ده بيجيب عروض أمازون مصر، ويحوّل كل اللينكات للتاج بتاعك `tahergalaleld-21`، وينزلها على قناة التليجرام لوحده.
بيشتغل على GitHub Actions، يعني مش محتاج اللاب يفضل مفتوح.

## بيعمل إيه

- بيدوّر لوحده كل 3 ساعات على عروض في الكلمات اللي تختارها (موبايلات، سماعات، باور بانك…) وياخد أحسنها (محتاج الـ Creators API).
- بياخد أي لينك أو رسالة تبعتهاله في الخاص، ويحوّل كل لينكات أمازون فيها للتاج بتاعك، حتى المقصّرة زي `amzn.eu` و`bit.ly`.
- بيشيل تاج أي حد تاني، ومنشنات القنوات التانية، واللينكات اللي مش أمازون.
- بينزل البوستات واحد واحد كل نص ساعة، في مواعيد النشر بس (من 10 الصبح لحد 1 بالليل).
- بيحدّث السعر قبل النشر، ولو العرض خلص أو المنتج نفد مبينزلوش.

## التشغيل لأول مرة (حوالي 15 دقيقة)

### الخطوة 1: اعمل البوت على تليجرام

- افتح [@BotFather](https://t.me/BotFather) واكتب `/newbot` واختار اسم ويوزر للبوت.
- هيديك توكن شكله كده `123456789:AAH...`، احتفظ بيه.
- ادخل على قناتك، ومن Administrators ضيف البوت أدمن بصلاحية نشر الرسائل (Post Messages).

### الخطوة 2: اعرف الـ ID بتاعك على تليجرام

- ابعت أي رسالة لـ [@userinfobot](https://t.me/userinfobot) وهيردلك برقمك.
- أو سيبه فاضي دلوقتي، والبوت نفسه هيبعتلك رقمك أول ما تكلمه.

### الخطوة 3: ارفع المشروع على GitHub

- اعمل ريبو جديد واختار **Private**.
- فك الضغط عن الملف، ومن صفحة الريبو دوس Add file ثم Upload files، واسحب كل اللي جوه الفولدر.
- خلي بالك: فولدر `.github` بيبقى مستخبي على الماك. في Finder دوس `Cmd + Shift + .` عشان يظهر، ولازم يترفع لأنه هو اللي بيشغّل البوت.

### الخطوة 4: حط الأسرار (Secrets)

- من الريبو ادخل على Settings، ثم Secrets and variables، ثم Actions، ودوس New repository secret لكل واحد من دول:
- التوكن: `TELEGRAM_BOT_TOKEN` (التوكن من BotFather)
- القناة: `TELEGRAM_CHANNEL` (يوزر القناة بالـ @، زي `@taherreviews`)
- رقمك: `TELEGRAM_ADMIN_IDS` (الـ ID بتاعك، ولو أكتر من حد افصل بينهم بفاصلة)

### الخطوة 5: افتح الـ Creators API (اختياري، بس هو اللي بيجيب الأسعار)

- ادخل على حسابك في affiliate-program.amazon.eg، ومن Tools اختار Creators API، ودوس Create Credential.
- هتاخد 3 حاجات: Credential ID و Credential Secret و Version.
- حطهم في 3 Secrets بالأسماء دي: `AMAZON_CREDENTIAL_ID` و `AMAZON_CREDENTIAL_SECRET` و `AMAZON_CREDENTIAL_VERSION`.
- لو الصفحة مش راضية تفتح، أو البوت قالك إن الـ API مقفول: أمازون بتشترط 10 مبيعات مؤهلة في آخر 30 يوم.
- البوت هيفضل شغال في تحويل اللينكات لحد ما توصل للرقم ده، وأول ما الـ API يفتح هيبدأ يجيب الأسعار ويدوّر لوحده من غير ما تغير أي حاجة.

### الخطوة 6: شغّله

- ادخل على تبويب Actions، واختار deals-bot، ودوس Run workflow.
- ابعت للبوت `/test` وهيرد عليك بشكل البوست (الرد بييجي في الـ run اللي بعده).
- بعد كده هيشتغل لوحده كل نص ساعة.

## الاستخدام اليومي

- لينك منتج: بيعمله بوست بالصورة والسعر والخصم والتقييم.
- لينك بحث أو قسم من أمازون: بيجيب أحسن العروض اللي فيه (لحد 8 منتجات).
- لينك صفحة عروض أو إيفنت (زي الجمعة البيضاء): بوست واحد بلينك الصفحة بالتاج بتاعك.
- رسالة من الجروب (اعملها forward للبوت): بينزلها زي ما هي بصورتها، بعد ما يغيّر كل اللينكات للتاج بتاعك ويشيل منشنات القنوات التانية.
- كل البوستات بتدخل طابور وبتنزل واحد ورا التاني عشان القناة متتزحمش.

### الأوامر

- اكتب `/now` في أول الرسالة: تنزل فوراً من غير طابور.
- اكتب `/raw` في أول الرسالة: تنزل زي ما هي باللينكات بتاعتك.
- اكتب `/rich` في أول الرسالة: كل منتج ياخد بوست لوحده بالسعر والصورة.
- الأمر `/queue`: حالة البوت والطابور والـ API.
- الأمر `/pause` أو `/resume`: وقف أو رجّع النشر.
- الأمر `/clear`: يفضّي الطابور.
- الأمر `/wa`: يبعتلك عروض النهارده مكتوبة بتنسيق واتساب، تنسخها وتنزلها.
- الأمر `/test`: يبعتلك شكل بوست تجريبي.

### النشر على واتساب

- تحت كل بوست في القناة فيه زرار "شير على واتساب": بيفتح واتساب والبوست مكتوب جاهز بلينكك، وإنت تختار الجروب أو الشخص.
- الزرار ده ظاهر للمتابعين كمان، فأي حد يشير عرض لصحابه بيشيره بالتاج بتاعك.
- لقناة واتساب: ابعت للبوت `/wa`، وهيبعتلك كل عروض النهارده بالبولد والشطب بتاع واتساب، انسخها والصقها في القناة.
- اللينك ظاهر في نص كل بوست، فلو نسخت البوست من تليجرام على طول اللينك بيتنسخ معاه.
- لو مش عايز الزرار: خلي `whatsapp_button: false` في `config.yaml`.

## تعديل الإعدادات

- كل الإعدادات في ملف `config.yaml`، وتقدر تعدّله من موقع GitHub نفسه: افتح الملف، دوس على القلم، عدّل، ودوس Commit.
- مواعيد النشر: `active_from` و `active_to`.
- المسافة بين البوستات: `min_gap_minutes`.
- أقصى عدد بوستات في اليوم: `max_posts_per_day`.
- أقل نسبة خصم للبحث الأوتوماتيك: `min_saving_percent`.
- كلمات البحث: قايمة `searches`، زوّد أو شيل براحتك.
- رسائل الجروب: `text_messages` (خليها `rich` لو عايز كل منتج في الرسالة ياخد بوست بالسعر بدل ما الرسالة تنزل زي ما هي).

## ملاحظات مهمة

- الإفصاح: أمازون بتطلب توضّح إنك شريك في البرنامج. حط في وصف القناة جملة زي: "بصفتي شريك في برنامج Amazon Associates، بكسب عمولة من عمليات الشراء المؤهلة".
- الأمان: البوت مش بيفتح صفحات أمازون ولا بيعمل scraping، لأن ده ممنوع في شروط أمازون وممكن يقفل حساب الأفلييت. اللينكات المقصّرة بيفكها من غير ما يحمّل الصفحة، والأسعار كلها من الـ Creators API الرسمي.
- التكلفة: الريبو الـ Private بيستهلك حوالي 1,440 دقيقة في الشهر، وده جوه الرصيد المجاني بتاع GitHub.
- السرعة: البوت بيقرا رسايلك كل نص ساعة، فالرد مش فوري. لو عايزه أسرع، خلّي الريبو Public (الـ Actions فيه مجاني من غير حد، والأسرار بتفضل مستخبية) وغيّر `*/30` لـ `*/10` في ملف `.github/workflows/deals-bot.yml`.
- تليجرام بيحتفظ برسايلك للبوت 24 ساعة، فمفيش رسالة هتضيع لو الـ run اتأخر.

## لو حاجة مش شغالة

- البوت مش بيرد عليك: اتأكد إن `TELEGRAM_ADMIN_IDS` فيه رقمك الصح، وإن الـ runs شغالة في تبويب Actions.
- البوت مش بينزل على القناة: لازم يكون أدمن بصلاحية النشر، و`TELEGRAM_CHANNEL` مكتوب بالـ @. البوت هيبعتلك تنبيه لو المشكلة دي حصلت.
- خطوة Save state بتفشل: ادخل Settings، ثم Actions، ثم General، وفي Workflow permissions اختار Read and write.
- البوت بيقول الـ API مقفول: راجع الخطوة 5.

## للتجربة على جهازك

- التشغيل التجريبي من غير نشر: `python -m bot.main --dry-run`
- الاختبارات: `pip install pytest && python -m pytest`
